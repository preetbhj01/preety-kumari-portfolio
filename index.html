01 / 3D ENVIRONMENT

Cozy Study Workspace.

A presentation-ready interior scene designed around a calm, productive workspace. The visual language combines warm daylight, practical task lighting, natural materials and layered décor to create depth and a lived-in feel.

Project type3D Environment / Interior
Visual directionWarm · Modern · Lived-in
Core focusComposition · Lighting · Materials
PresentationFinal render + breakdown board

Objective

Create a visually coherent workspace where the primary desk area reads immediately, while secondary assets support scale, personality and depth.

Approach

The scene is organized into a clear visual hierarchy: window light establishes atmosphere, the desk anchors the composition, and shelves, plants, books, pin-board elements and lighting create secondary points of interest.

3D breakdown

The project documents the base model, textured model and wireframe, followed by material maps and focused studies of wood, drawers, chair, shelf, plant and lamp assets.

Key deliverables

Final environment renderScene overviewAsset detail studiesBase / textured modelWireframe viewTexture maps
02 / 3D CHARACTER

Character Turnaround.

A stylized character presentation focused on consistency across views and expressions. The board combines a hero render with front, side and back references, wireframe visualization and material/detail studies.

Project type3D Character / Stylized
Character designFriendly · Contemporary
Core focusForm · Hair · Clothing · Face
PresentationTurnaround + expression sheet

Objective

Build a character reference board that communicates the model from every important angle while demonstrating how the final look is supported by modeling and material work.

Approach

The character is presented through a hero pose and consistent front, right, back and left views. Facial expressions extend the model beyond a static asset and demonstrate visual range.

Technical breakdown

The lower panel documents the base model, textured model and wireframe alongside albedo, normal, roughness and ambient-occlusion maps. Close-ups highlight eye, hair, fabric and shoe materials.

Key deliverables

Hero character render4-view turnaroundWireframeExpression sheetTexture mapsMaterial details
